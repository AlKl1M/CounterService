# Проект для теста функциональности gradle относительно написания кастомных задач.

Проект содержит java spring api и тесты для него, но эта часть не содержит интереса, т.к. написана просто для галочки (погонять тесты итп)

Основу составляет dev-tasks.gradle & test-tasks.gradle

В test-tasks.gradle описаны "не имеющие практического применения" задачи, просто для теста функционала.

В dev-tasks.gradle написан функционал, расширяющий checkstyle, а также своя реализация инструмента версионирования на основе коммитов и тэгов.

### Функционал test-tasks.gradle:

1. **hello**
    - Выводит приветственное сообщение: "hello, world".

2. **copyResources**
    - Копирует все XML файлы из директории `src/main/resources` в директорию `build/copy-resources`, исключая файлы в подпапке `temp`.

3. **generateVersionFile**
    - Генерирует файл `version.txt`, в который записывается версия проекта и дата его создания.

4. **deepClean**
    - Очищает директории `logs`, `tmp`, `out`, а также зависит от задачи `clean`.

5. **projectInfo**
    - Выводит информацию о проекте, включая имя, версию, группу и корневой проект.

6. **countCodeLines**
    - Подсчитывает количество строк кода во всех файлах с расширениями `.java`, `.kt`, `.groovy` в директории `src`.

7. **gitStatus**
    - Выполняет команду `git status` и выводит результат в лог.

### Функционал dev-tasks.gradle

1. **customCheckstyle**
    - Выполняет проверку кода с помощью Checkstyle. Если найдено нарушение, генерирует отчет и выбрасывает исключение.

2. **generateChangelog**
    - Генерирует файл `changelog.md`, основанный на тегах Git, и выводит изменения между тегами в виде списка коммитов.
